# Spec Driven Development 0.1.0

Reconstructs the seven photographed workflow skills as a self-contained Codex plugin:
`ideate`, `build-author`, `pre-dev-prep`, `tdd`, `pr-author`, `merge-manager`, and
`close-milestone`. This is an original implementation of visible behavior, not a
copy of the unavailable source.

Includes shared authorization and independent-review contracts, planning and review
templates, a repository marketplace entry, and Python 3.11+ helpers for package
validation, read-only branch inventory, and preview-first milestone archival.
Bounded milestone authority carries across covered phases. Merge, deployment, and
final human acceptance retain their separate authorization gates.

The archive helper requires a clean named branch, a committed completion record,
matching reviewed implementation evidence, safe declared paths, and an unchanged
preview digest. It preserves supported relative Markdown links and rejects ambiguous
forms. Caught-error rollback is best effort; concurrent writers and crash recovery
are not supported. Remote evidence truth and action authority remain caller checks.

Validation uses 24 isolated tests and package checks. Review reports and exact
reviewed revisions are recorded on PR1. Fixture verification does not establish a
complete live project trial, plugin installation/discovery, or real GitHub merging.
There is no rendered UI change, so screenshot evidence is not applicable.

Existing standalone skills remain unchanged. Publishing this bundle does not install
it, edit global Codex settings, merge the PR, or deploy any service.
